Распределение чаевых

Комиссия 8% учитывается автоматически.

Официант 1 0 ₽
Официант 2 0 ₽
Официант 3 0 ₽
Общая часть после 8%: 0 ₽
Доля общей части на одного: 0 ₽
Утро + вечер после 8%: 0 ₽
Доплата официантам 1 и 2: 0 ₽
Всего распределено: 0 ₽
Формула: ((Итог − Утро − Вечер) × 0,92) ÷ 3; ((Утро + Вечер) × 0,92) ÷ 2.
